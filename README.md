# 口岸高峰勤务与异常分流

编排机场口岸高峰期的通道、人员、设备和异常查验。

## 领域范围

系统涉及边检值班长、查验人员、复核人员、航班保障人员。当前领域资料记录以下业务事实：

- 假期口岸客流和航班保障量明显增长
- 通道需要依据实时流量动态增开
- 旅客证件有效期和材料完整性会影响通关

后续实现需要围绕这些边界组织服务：

- 客流预测版本
- 通道人员排程
- 乱序航班事件
- 异常分流权限
- 岗位租约恢复

`contracts/domain.schema.json` 定义领域资料结构，`fixtures/domain.json` 提供不含真实身份信息的示例，`src/border_peak_duty/context.py` 负责读取并检查这些资料。

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译检查：`python3 -m compileall -q src`

上述命令只读取仓库内资料，不需要连接外部业务服务。
