# 口岸高峰勤务与异常分流

编排机场口岸高峰期的通道、人员、设备与异常查验，解决航班延误、设备检修、
换班交接叠加时旅客被漏计或重复计算的问题。

## 统一时间线

系统把以下输入汇入同一条 15 分钟时间槽时间线：

- **航班计划及后续动态**（`timeline.FlightLog`）：计划/延误/集结/离场/取消
- **分时客流预测**（`timeline.ForecastBook`）：按版本管理，系统始终使用最高版本
- **通道能力与设备状态**（`resources`）：自助通道、人工通道、二线/放行台位
- **人员资质**（`resources.Staff`）：普通查验、二线复核、最终放行三类资质

航班事件规则：

- 事件按版本号定序，乱序到达的低版本事件一律拒绝；
- 同一动态（相同 `event_id`）重发只更新对应版本，不产生第二条记录；
- 航班离场/取消进入终态后，任何占用性动态都不能让它重新占用资源；
- 取消航班贡献 0 客流，离场航班按实际时间截断占用窗口。

## 调度产出

`Scheduler.plan_slot` 为每个时间槽产出 `SlotPlan`：

- 开放通道（通道、岗位、持证人、租约号）
- 岗位组合（普通查验 / 二线复核 / 最终放行的需求数、已开数、备用数、缺口）
- 备用容量（未启用通道能力、可调配人员）
- 触发原因（预测上冲、延误叠加、设备降效、人员不足、队列升级、交接重建、设备恢复）

## 岗位租约

`leases.LeaseRegistry` 是「人员占用岗位、岗位绑定通道」的唯一权威：

- 一人一槽一岗；一个通道单元一槽一份租约；资质不符不可占位；
- **调配、交接、设备恢复补位走同一套获取/释放规则**；
- 交接原子完成：新租约获取失败时旧租约保持有效；
- 设备检修立即失效相关租约并释放人员，设备恢复后按同一规则补位；
- 租约有到期时间；获取不到资源的请求进入等待队列，带升级期限与最终期限；
- 调度发布在事务中预占全部租约，外部发布成功才提交，失败整体回滚——
  绝不留下「人员已占用、通道未启用」的中间状态。

## 异常分流案件

`cases.CaseBook`：

- **最小化留痕**：旅客以 HMAC 假名标识，只存原因代码、槽位、航班号与各阶段结论；
  原始证件令牌不落盘，备注携带原始信息会被拒绝；
- **三阶段隔离**：普通查验只能立案分流，二线复核只能给结论，最终放行只能放行/拒绝；
  三类通道单元与人员互不可跨；
- **发起人不能批准自己的结论**，且各阶段处置人必须互不相同；
- 处置必须持有对应岗位的有效租约；租约失效（到期、检修、交接）后提交结论
  抛出 `SlotClosedError`，系统 tick 后案件退回等待队列，不丢案、不双计；
- 同一旅客有未结案件时重复立案返回原案件，不会进入两个队列。

## 值班接口

- `GET /board?slot=...`：当前拥堵源、剩余能力（已开放/即时余量/备用）、
  开放通道、案件队列与等待请求的升级期限；
- `GET /cases/{id}/chain`：脱敏决定链，说明旅客为何被分流、各阶段由谁处置；
- 命令路由见 `src/border_peak_duty/api.py`（航班动态、预测、设备、发布、
  交接、恢复、分流案件、时间推进）。

## 重启恢复

每次命令成功后写入原子快照（临时文件 + fsync + rename）。
服务重启后，等待队列、租约（含到期/升级期限）、案件进度、航班终态与时间线
全部从快照恢复并继续有效，见 `store.JsonSnapshotStore` 与 `HostedApp.restart`。

## 代码结构

```
src/border_peak_duty/
  clock.py       时钟、时间槽
  timeline.py    航班动态状态机、预测版本、分时需求
  resources.py   通道/设备/人员资质台账
  leases.py      岗位租约、等待队列、事务与快照
  scheduler.py   分时规划、岗位组合、备用容量、原子发布
  cases.py       分流案件、三阶段隔离、脱敏决定链
  service.py     应用内核（统一编排）
  store.py       原子 JSON 快照
  app.py         命令分发、自动快照、重启恢复
  api.py         HTTP 薄适配层
  scenario.py    标准高峰场景构造（虚构数据）
```

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译检查：`python3 -m compileall -q src tests`

测试覆盖：乱序/幂等/终态航班事件、预测版本、调度产出与触发原因、
发布失败回滚、交接原子性、设备检修与恢复、等待升级期限、案件隔离与重排队、
脱敏留痕、重启恢复与 HTTP 接口。全部命令只读写本仓库，不连接外部业务服务。
